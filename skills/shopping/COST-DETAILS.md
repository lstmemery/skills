# Import and package cost branches

## Imports

When an offer crosses a customs boundary, capture origin, destination, product
classification where needed, Incoterm (such as DDP or DAP), and payer for each
charge. Verify applicable duties, VAT/GST/sales tax, brokerage/disbursement,
handling/storage, carrier advance fees, and whether freight/insurance enters
the taxable value. Keep import deposits and taxes already included distinct
from additional payable amounts. Preserve original currency and timestamped FX.

Use current customs/carrier authority sources for bounds; final determination
can differ. If classification, payer, tax, or brokerage cannot be established,
name the uncertainty and leave any unsupported expected or upper bound unknown.
Domestic offers do not inherit this branch merely because they have shipping.

## Package and dimensional weight

When charges depend on package size/weight, obtain packed dimensions, actual
weight, package count, carrier/service, current divisor, rounding rule, and
oversize/residential/remote/fuel/correction surcharges. Compute dimensional
weight from packed dimensions using that service's rule, then determine
billable weight. Do not substitute product dimensions for packed dimensions.

Do not request weight data when a valid fixed checkout quote already covers
the exact shipment and no weight-based uncertainty remains. Historical divisor
examples in RETAILER-NOTES.md are source leads, not universal carrier rules.
